# NEXWORKS AGENCY

Site vitrine de **NEXWORKS AGENCY** — agence digitale (création web, design UX/UI, SEO, GEO).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Démarrage local

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).

## Variables d'environnement

Copie `.env.example` vers `.env.local` et renseigne tes valeurs (e-mail, Resend, URLs démo…).

## Démos portfolio

Sites fictifs inclus dans le repo :

- `/azur-plomberie` — artisan plombier
- `/maison-riviera` — immobilier de prestige

## Scripts utiles

```bash
npm run build
npm run typecheck
node scripts/process-logo.mjs
node scripts/capture-azur.mjs
node scripts/capture-riviera.mjs
```
